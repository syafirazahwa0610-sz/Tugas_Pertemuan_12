## Deskripsi

Tugas ini membuat fitur hapus banyak data buku sekaligus (bulk delete) pada aplikasi Laravel menggunakan checkbox pada halaman daftar buku.

## Fitur
1. Checkbox pada setiap data buku
2. Select All checkbox
3. Hapus banyak data sekaligus
4. Proses delete menggunakan Laravel whereIn()

## Cara Kerja
1. User memilih beberapa buku menggunakan checkbox
2. Klik tombol Delete Selected
3. Data yang dipilih dikirim ke controller
4. Sistem menghapus data sekaligus dari database
